七、相机视角功能（新增 2026-10-13）
------------------------------------------------------------
功能：
  1. 视角跟随 —— 相机自动平滑跟随无人机移动（默认模式）
     · 相机始终 lookAt 无人机位置，跟随目标实时锁定
     · 无人机飞到哪，相机就平滑追踪到哪（lerp 系数 0.12）
     · 相机位置由球坐标 (dist, theta, phi) 相对无人机位置计算

  2. 长按转移视角（手动模式）
     · 按住鼠标左键拖动 = 进入"手动视角"：
         水平拖动 → 旋转方位角 theta（绕无人机环绕）
         垂直拖动 → 调整俯仰角 phi（从上/从下看）
     · 松开鼠标 = **视角锁定在松开前的位置，不再变动**（保持 autoFollow=false）
     · 相机仅跟随无人机移动（朝向不变），不会自动拉回跟随角度
     · 滚轮 = 缩放相机距离 dist（范围 10~120）
     · 再次按住拖动 = 从当前锁定角度继续调整
     · 重新开始飞行（showFlightScreen）= 重置回自动跟随模式

  3. 视角状态提示（HUD）
     · 初始/跟随：显示"🎥 自动跟随 · 🖱 按住左键拖动=自由视角 · 🖲 滚轮=缩放 / 📌 松开后锁定当前视角"（灰色）
     · 拖动中：显示"🎥 手动视角 · 松开锁定当前角度 · 🖲 滚轮=缩放"（橙色高亮）
     · 松开后：显示"🎥 自由视角已锁定 · 🖱 再次拖动可调整 · 🖲 滚轮=缩放"（橙色高亮）

  4. 鼠标光标
     · 默认：grab（手形，暗示可拖动）
     · 拖动中：grabbing（抓手形）

改动文件：demo.html
  - 新增 camOrbit 状态对象（球坐标相机参数）
  - 新增 updateCamera() 函数（根据 camOrbit 计算相机位置）
  - updateScene() 重写相机逻辑（旧固定偏移 → 球坐标跟随 + 模式切换）
  - 新增 mousedown/mousemove/mouseup 事件（长按拖动）
  - 新增 wheel 事件（滚轮缩放）
  - 新增 hud-cam-hint 提示元素
  - showFlightScreen() 重置相机到初始状态
  - initThree() 初始化 camOrbit 参数
  - CSS：#three-canvas cursor:grab / grabbing，.cam-hint 样式

技术说明：
  - 球坐标相机 = 目标位置 + dist*(sinφ·sinθ, cosφ, sinφ·cosθ)
  - θ（theta）= 水平方位角，φ（phi）= 俯仰角（φ>0 表示相机在目标上方）
  - 手动模式时锁定 userTheta/userPhi；松开后 autoFollow 保持 false
    → 相机角度不向 followTheta/followPhi 收敛，视角保持不动
  - showFlightScreen() 会重置 autoFollow=true，重新开始飞行回到默认跟随

验证：
  - 语法检查通过（node new Function 两段 inline script 均 OK）
  - 视角交互事件绑定完整（mousedown/mousemove/mouseup/wheel）

============================================================
需求：底层代码加入限制——无人机自身事件（内部故障）触发后，
应当立即就近迫降，且终止任务（后续事件不再处理）。

自身事件白名单（DroneAI.SELF_FAULT_TYPES，7类）：
  motor_failure / flight_ctrl / battery_issue /
  prop_break / esc_fault / gimbal_fault / payload_fault
外部因素（雨/风/GPS/障碍/鸟/链路/打雷）仍走 RTB 返航，不终止任务。

改动文件：
  drone_ai/ai_main.py
    - __init__：新增 task_aborted=False / task_abort_reason=None / task_abort_ts=None
    - start()：每次新任务重置三项
    - tick() 第5.5)段：atype 命中 SELF_FAULT_TYPES 且未已终止 -> 调 _force_land_abort()
    - 新增 _force_land_abort(cmd, metrics, atype, now_ms)：
        dx=dy=dvyaw=0（水平/偏航收敛稳着落）
        dz=T.RTB_DESCENT_MPS*1.5=3.0（强下降迫降）
        throttle_delta=-0.3（油门收敛，防动力故障恶化）
        清除 rtb/mode_action/obstacle_action/obstacle_reason 残留
        cmd[force_land]=self_fault_force_land, cmd[task_aborted]=True
        self.task_aborted=True, task_abort_reason=atype, task_abort_ts=now_ms

  drone_sim/simulate.py
    - __init__：新增 self._task_terminated=False, self._task_terminate_ts=None
    - run() 主循环：self._ai.task_aborted 为 True 时
        记 [CRIT] 行"任务终止 | 自身事件[xx] 立即就近迫降 | 后续事件不再处理"
        self._task_terminated=True, self._task_terminate_ts=ts, break
    - run() 循环尾：_task_terminated 时
        记 [CRIT] "飞行提前终止 | 自身事件[xx] 迫降 | 已处理事件 N/M | 任务未正常完成"

    - _task_terminate_ts 用模拟秒 ts（0起算），不用墙钟 now_ms
